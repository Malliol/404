# Урок 1. Каркасная конфигурация. Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=baFxKi0Jcj4 · 55 мин · [полный текст](../transcripts/001_baFxKi0Jcj4.md)

## О чём урок
Вводный урок цикла. Автор сам готовится к экзамену «1С:Специалист по платформе» и делится находками. Экзаменационные билеты он не видел и не разбирает, а рассказывает про требования и приёмы. На уроке готовят рабочую среду: настраивают каркасную конфигурацию, интерфейс, консоль запросов и пересчёт сумм в документах.

## Подготовка
- На сайте 1С: «Курсы и экзамены» → экзамен «Специалист по платформе» → требования к экзамену и примеры билетов.
- Нужно скачать **каркасную конфигурацию**. Задачи на экзамене решают только в ней, пустую конфигурацию использовать нельзя.
- В каркасе уже есть справочники, документы, перечисления, обработки и регистры. Часть свойств в нём выставлена неправильно. Например, у регистра накопления «Остатки номенклатуры» снят флажок «Разрешить разделение итогов», хотя его рекомендуется оставлять включённым. Такие «подставы» нужно знать и проверять.

## Командный интерфейс
Исходно все объекты свалены в одну строку, а на экзамене требуется навести порядок.

1. **Подсистемы верхнего уровня:** «Оперативный учёт», «Бухгалтерский учёт», «Расчёты», «Бизнес-процессы». Именно по ним на экзамене делятся задачи. Для подсистем в каркасе уже есть картинки, и они подсказывают нужный набор.
2. **Порядок разделов:** ПКМ на корне конфигурации → «Открыть командный интерфейс конфигурации». Подсказка: пока в подсистемах нет объектов, раздел может не отображаться в этом окне.
3. **Группировка объектов внутри раздела** возможна двумя способами:
   - вложенные подсистемы («Справочники», «Документы», «Регистры сведений» и т. д.);
   - **группы команд.** Это удобнее: меньше дублирования подсистем. Создаёшь группы команд «Справочники», «Документы» и т. п., затем в подсистеме открываешь командный интерфейс и перетаскиваешь объекты по группам.
4. Объекты, которые видеть не нужно (например, перечисление «Учётная политика»), не включают в группу.
5. Валюта и другие объекты, добавленные для проверки, из подсистем нужно убрать.

## Панели интерфейса
Настройка через «Сервис → Параметры → Интерфейс» или настройку панелей:
- скрыть панель функций текущего раздела, тогда список открывается за один клик;
- панель открытых окон можно вынести вниз;
- панель разделов можно вынести влево.

## Консоль запросов
Решить задачи без консоли запросов практически нереально, а на экзамене экзаменатор может попросить её запустить. Консоль идёт как обработка с **обычной формой**, поэтому в управляемом приложении она сразу не запустится.

1. Сервис → Параметры → режим совместимости/использования: включить «Управляемое и обычное приложение». После этого в свойствах конфигурации становится доступна нужная настройка.
2. Обычные формы работают только в **толстом клиенте**. Чтобы не выбирать его каждый раз, в параметрах задают «Толстый клиент» как основной режим запуска.
3. Ошибка «Использование модальных окон в данном режиме запрещено»:
   - вместо `Предупреждение()` использовать `ПоказатьПредупреждение(, "Текст")` (в справке: Ctrl+F1);
   - свойство «Режим использования модальности» **не менять**. Оставить «Не использовать» (современный стандарт).
4. **Важно:** после подготовки вернуть режим запуска на «Автоматически» или «Тонкий клиент». Экзаменатор может снять балл, если приложение не проверялось под тонким клиентом.

## Пересчёт сумм в документах
Приходная и расходная накладные в каркасе не пересчитывают суммы: можно ввести количество 5, цену 12, сумму 98 и итог 50 000. На экзамене автоматический пересчёт, по словам автора, не требуется. Но делать его удобно, чтобы не считать в уме.

**Логика (на форме документа):**
- Реквизит «Сумма документа» делают недоступным для редактирования (поле надписи).
- События «ПриИзменении» для полей «Количество», «Цена», «Сумма» вызывают процедуру `ПересчетСтроки(ТекущаяСтрока, ПересчитатьСумму)`:
  - при изменении количества или цены: `Сумма = Количество * Цена`;
  - при изменении суммы: `Цена = Сумма / Количество`, с проверкой деления на 0. Если количество нулевое, оно становится 1;
  - количество не пересчитывается, потому что оно целое (точность 0).
- Обращение к текущей строке: `Элементы.СписокНоменклатуры.ТекущиеДанные`.

**Вынос в общий модуль.** Чтобы не дублировать код в каждом документе:
- Создать общий модуль («ОбщегоНазначения» или «ОбработкаТабличныхЧастей») с флагом «Клиент (управляемое приложение)».
- В него вынести `ПересчетСтроки(Форма, ТекущаяСтрока, ПересчитатьСумму)`.
- В каждой форме документа создать экспортную процедуру `ОбновитьИтоги()`, которая считает итог по колонке «Сумма». Общий модуль вызывает её через переданную форму.
- Забытый флаг «Экспорт» даёт ошибку «Метод не обнаружен».

**Дополнительные события:**
- «ПослеУдаления» строки: обновить итоги.
- При копировании строки обновить итоги: «ПередНачаломДобавления» с копированием подходит плохо. Сработало событие «ПриНачалеРедактирования» (проверка свойства копирования).
- Для документов, создаваемых программно, в модуле объекта в «ПередЗаписью» ставят `СуммаДокумента = ТабличнаяЧасть.Итог("Сумма")`.

## Замечания автора
- Перерасчёт на экзамене не обязателен. Стоит ли делать его, нужно решать по времени. На выполнение у автора уходит мало времени.
- Типовые конфигурации передают параметры пересчёта структурой. Здесь параметр всего один (`ПересчитатьСумму`), поэтому структура не нужна.
- Зрители в чате отметили, что количество иногда задают с точностью 3. Автор таких задач не видел.
- Дальше в цикле: контроль остатков, приход и расход товара, два способа контроля остатков.

## Шпаргалка
| Задача | Решение |
|---|---|
| Консоль запросов не запускается | Параметры: «Управляемое и обычное приложение» и толстый клиент |
| Ошибка модальных окон | Заменить `Предупреждение` на `ПоказатьПредупреждение` |
| Порядок разделов | Командный интерфейс конфигурации |
| Группировка объектов в разделе | Группы команд в командном интерфейсе подсистемы |
| Общий пересчёт строки | Общий модуль на клиенте + экспортная `ОбновитьИтоги` в форме |
| В конце подготовки | Вернуть режим запуска «Тонкий клиент» |
